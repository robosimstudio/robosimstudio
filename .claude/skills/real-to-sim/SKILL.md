# Real to sim on the live page

The method is [`examples/live/AGENTS.md`](../../../examples/live/AGENTS.md),
one file for every agent: how to work the page, the twin's own folder
(`./ctl new`), what a finished twin is and what the report says. Read it whole
before the first edit; every command, output file and reading, and the frames
and units, are in [`examples/live/REFERENCE.md`](../../../examples/live/REFERENCE.md).

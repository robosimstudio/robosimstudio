# Real to sim on the live page

The method, the commands and what counts as a finished twin are in
[`examples/live/AGENTS.md`](../../../examples/live/AGENTS.md), one file for
every agent (Codex reads it by itself). Read it whole before the first edit,
then [`examples/live/REFERENCE.md`](../../../examples/live/REFERENCE.md) for
every command, output file and reading, and the frames and units. Work from
`examples/live/`.
